# v260823

## 更新内容

- 未配置元宝 Cookie 时，也支持使用视频号解析分享链接（[#508](https://github.com/ltaoo/wx_channels_download/issues/508)）
- `Get` 页面支持使用第三方下载器下载视频号视频，目前仅测试过 aria2（[#477](https://github.com/ltaoo/wx_channels_download/issues/477)）
- 重复下载进行中的视频时，现在会正确显示错误提示（[#517](https://github.com/ltaoo/wx_channels_download/issues/517)）
- 支持下载公众号文章中的视频（[#518](https://github.com/ltaoo/wx_channels_download/issues/518)）
- MCP 服务支持更多命令，可获取视频号评论列表、直接创建直播下载任务等
- 前端页面增加版本号显示，发现新版本时支持直接下载更新并重启服务
- 优化前端页面样式和交互，下载任务详情和内容详情改为在抽屉中展示，不再打开新页面
- 移除「原始视频」菜单项（[#522](https://github.com/ltaoo/wx_channels_download/issues/522)）
- 修复 Windows 下文件名过长或包含特殊字符时未正确添加后缀、有时无法正常完成任务的问题（[#505](https://github.com/ltaoo/wx_channels_download/issues/505)）
- 修复无法访问日志页面 `http://127.0.0.1:2022/logs` 的问题
- 修复视频号详情接口缺少点赞数等字段的问题（[#519](https://github.com/ltaoo/wx_channels_download/issues/519)）
- 修复视频号评论列表接口没有返回数据的问题（[#519](https://github.com/ltaoo/wx_channels_download/issues/519)）
- 修复新版微信页面内嵌在聊天窗口时，无法触发 `onFetchFeedProfile` 和切换视频事件的问题（[#510](https://github.com/ltaoo/wx_channels_download/issues/510)、[#520](https://github.com/ltaoo/wx_channels_download/issues/520)）
