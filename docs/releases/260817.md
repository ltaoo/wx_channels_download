# v260817

## 更新内容

- 优化公众号推送列表面板样式，现在会展示封面，并支持直接下载列表中的推送
- 优化下载管理页面样式，增加侧边菜单
- 支持下载知乎文章
- 增加内容抓取页面，可通过 `http://127.0.0.1:2022/scraper` 访问，输入链接即可解析并下载内容
- 内容抓取页面会实时显示与视频号的连接状态，直观展示视频号能力是否可用
- 增加内容列表和内容详情页，可直接在详情页播放、查看已下载的视频和图片
- 增加账号管理页面
- 视频号页面的下载按钮增加下载器连接状态标志，可直观看到下载器是否可用
- 视频号页面会定时重连下载服务，重启下载器后无需刷新页面即可自动重连
- 增加 MCP 服务，可通过 Agent 直接下载视频号、公众号和知乎文章
- 前端「设置」页面支持查看下载器实际使用的根证书及其状态
- 部署和使用视频号分享链接解析服务的 Cloudflare Worker 时必须指定凭证信息。请勿向过多人共享，以免元宝账号被封禁（[#495](https://github.com/ltaoo/wx_channels_download/issues/495)）
- 修复某些情况下 macOS 代理无效的问题（[#478](https://github.com/ltaoo/wx_channels_download/issues/478)，感谢 [@BozhengLong](https://github.com/BozhengLong)）
- 修复无法下载原始视频的问题（[#489](https://github.com/ltaoo/wx_channels_download/issues/489)）
- 修复文档站 SunnyNet 根证书无法下载的问题
- 修复公众号图集类文章没有下载按钮的问题

::: warning 数据库版本兼容性

自 v260810 起，部分版本会修改数据库迁移文件，无法在新旧版本间随意切换。例如使用 v260817 后，不能直接切换回 v260810，因为 v260817 增加了更多功能并变更了数据库表结构，切换到旧版本会丢失新功能的数据。

如需切换回旧版本，可以让 AI 根据源码中的 `migrations` 迁移文件强制将数据库迁移回旧版本，完成后才能正常使用。

:::
