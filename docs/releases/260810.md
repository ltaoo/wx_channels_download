# v260810

一次非常大的改版，从3月开始写到8月，将近半年时间。其中也经历了许多次改版，一开始为了更强的自定义能力，实现非常复杂，后面功能全砍了，决定先迭代一部分功能。

这次迭代核心工作是为了后续支持更多平台的下载，所以架构做了很大的调整，同时为了支持更复杂的功能，下载器从 `gopeed` 切换到自研。


## 更新内容

- 支持保存视频号和公众号的浏览记录，可以通过 `http://127.0.0.1:2022/browsehistory` 访问浏览记录页面
- 增加了获取「视频号浏览记录」接口 `/api/channels/play/history`
- 下载面板的下拉菜单增加「刷新」等菜单
- 修复了视频号标题过长导致下载的文件没有文件后缀的问题
- 修复了下载器启动失败时看不到错误提示的问题
- 修复了「视频号解析」接口没有原样返回响应值的问题
- 修复了下载器影响了评论区及部分页面图标大小的问题
