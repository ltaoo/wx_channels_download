# 创作者视频同步

逐页检查创作者视频的本地下载任务，只提交缺失视频的下载任务，遇到整页已存在时停止。

点击下方代码块右上角的复制按钮，将完整 JSON 粘贴到「自动化 → 导入 Pipeline」。导入后点击流程的「配置」，填写 `username` 和可选备注。示例已内置每天 12:00、18:00 的定时触发规则。

更多说明见[导入和配置](./index.md#导入和配置)与[运行结果与边界](./index.md#运行结果与边界)。
