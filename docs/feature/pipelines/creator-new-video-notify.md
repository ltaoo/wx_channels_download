# 创作者新视频通知

按本地下载任务判断新视频，扫描完成后通过企业微信机器人或通用 Webhook 逐条推送消息。

点击下方代码块右上角的复制按钮，将完整 JSON 粘贴到「自动化 → 导入 Pipeline」。导入后点击流程的「配置」，填写 `username`、推送方式、接口地址及可选 token、消息模板。自动监控需在开始节点添加定时触发器，建议 Cron 为 `*/5 * * * *`。

第一次运行就会通知扫描范围内没有下载任务的视频；仍未创建下载任务的视频可能在后续运行中再次通知。详细配置见[新视频通知的额外配置](./index.md#新视频通知的额外配置)。
