# 下载公众号文章

首先在配置文件中开启公众号功能：

```yaml
mp:
  enabled: true
```

保存配置并重启下载器。打开公众号文章页面后，即可在页面底部看到「下载」按钮。

![公众号文章下载按钮](../../assets/mpdownloadbutton.png)

点击「下载」按钮，即可将文章内容下载为 HTML 文件。

点击「下载」按钮旁的下拉菜单，可以使用更多公众号文章相关功能：

![公众号文章下载下拉菜单](../../assets/mpdropdownmenu.png)

> 「推送列表」和「下载所有推送」为实验性功能。
