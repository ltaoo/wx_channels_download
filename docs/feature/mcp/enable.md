# 启用 MCP

正常启动下载器后，内置 MCP 默认关闭。打开页面 http://127.0.0.1:2022/ 点击左下角「设置 → MCP」可以查看连接地址并启用或停用服务。

> 设置页中的开关只在当前进程内生效，不写入配置文件；下载器下次启动时 MCP 会重新默认关闭。

默认地址为：

```text
http://127.0.0.1:2022/mcp
```

手动开启 MCP 服务后，在 AI 客户端中新增 Streamable HTTP 类型的 MCP Server，并填入这个地址即可

> 也可以这样对 agent 如 codex 说
> 
> ```bash
> 添加 MCP 服务，名称为 dm，地址为 http://127.0.0.1:2022/mcp ，类型为 Streamable HTTP
> ```

添加好之后就可以通过对话调用下载器的功能了，**保持视频号页面打开状态** 后，可以这样对 codex 说

```bash
使用 dm MCP 服务 查找昵称为 我不叫龙虾 的视频号账号，获取最新的10条视频
```

还可以这样说

```bash
使用 dm MCP 服务 查找昵称为 我不叫龙虾 的视频号账号，下载所有视频，跳过已下载的视频
```

对 codex 直接说出需求即可，现在还支持

- 下载视频评论列表
- 获取指定视频号账号的直播回放列表
- 获取视频详情
- 删除已下载的视频
- 下载指定链接的视频
- 获取已下载的视频列表
