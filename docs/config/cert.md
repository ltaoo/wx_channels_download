# 自定义根证书

用于配置自定义证书与私钥。启用代理启动时，指定的证书必须可读、与私钥匹配，并且已经安装且受系统信任，否则程序报错退出。

## 配置键

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `cert.file` | `""` | 自定义证书文件的绝对路径，支持 `.pem`、`.cer`、`.crt`、`.key` |
| `cert.key` | `""` | 自定义私钥文件的绝对路径，支持 `.pem`、`.key` |
| `cert.name` | `"Echo"` | 证书名称，用于在系统证书库中识别、安装和卸载证书 |

## 示例（config.yaml）

```yaml
cert:
  file: "C:/path/to/mycert.pem"
  key: "C:/path/to/mykey.pem"
  name: "MyProxyCA"
```

## 生效规则

- `cert.file` 和 `cert.key` 必须同时配置，两个文件都可读，且证书与私钥匹配。
- 未配置 `cert.name` 时使用默认值 `Echo`。
- 启动时先校验 `cert` 配置的证书；证书文件、私钥、安装或信任状态不满足要求时，直接报错退出，不会自动安装或切换到其他证书。
- 未配置证书时，依次检查 SunnyNet、mitmproxy，仅复用证书与私钥匹配、已安装且受系统信任的证书；复用时不创建本机证书，也不写入 `cert` 配置。
- 新生成的自有根证书默认名称和颁发者均为 `wx_channels_download`，组织为 `dm.funzm.com`；已有证书需要重新生成并安装才会采用新身份信息。
- 未配置证书且没有可复用的受信任证书时，生成本机专属根证书并保存到工作目录的 `certs/` 下，自动安装并验证信任成功后，才将路径和名称写回配置，后续启动复用。
- 已配置的证书不可读、格式无效或私钥不匹配会导致启动报错，请修复配置；有效配置始终优先使用，不会自动替换。
- `cert.file` 和 `cert.key` 应填写绝对路径。
- `proxy.skipInstallRootCert` 不会绕过上述启动校验或首次生成证书的安装、信任验证。纯 `server` 模式或 `proxy.enabled: false` 不生成、安装证书，但仍会校验已配置的证书。

## 注意事项

- 证书与私钥必须属于同一密钥对。
- `cert.name` 应与证书的通用名称（CN）一致，否则可能无法正确检测或卸载已安装的证书。
- macOS 默认安装到当前用户的“登录”钥匙串并设置用户级信任；通过 `sudo` 启动时切回原用户操作证书。
- Windows 安装或卸载证书需要管理员权限，具体操作参考[手动安装根证书](../guide/certificate.md)。
